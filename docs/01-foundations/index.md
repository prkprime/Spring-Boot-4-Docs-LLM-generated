# Part I — Foundations

The minimum you need to be productive: a running app, a working dev loop, configuration, what's *actually* new in Spring Boot 4, and your first test.

By the end of Part I you will have:

- A Spring Boot 4.0.6 project running on Java 25, scaffolded with Maven while Gradle generation is blocked upstream.
- A live-reloading dev environment.
- A clean understanding of `application.yml`, profiles, and `@ConfigurationProperties`.
- A correct mental model of what SB4 + SF7 changed (and what it *didn't*).
- A green JUnit 6 test, including the new SF7 `RestTestClient`.
