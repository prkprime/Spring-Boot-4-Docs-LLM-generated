# Part VII — Mini-projects

Mini-projects take one topic that is too large for a normal ladder chapter and build a focused application around it.

The first mini-project is passkeys. Passkeys are not just another authentication filter. They involve browser APIs, relying party identity, origin checks, short-lived challenges, credential storage, account recovery, and a production-grade verification library.
