# Part VI — Capstone

The capstone combines the main path of the guide into one deployable backend:

- Spring MVC REST endpoints.
- Postgres persistence with Flyway migrations.
- JWT resource-server security.
- Full integration tests with Testcontainers.
- Actuator health probes.
- Docker packaging.
- Fly.io deployment configuration.
